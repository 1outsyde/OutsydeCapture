FIX 1 — Show a role selection modal after Google/Apple auth for new users
The problem: When a new user taps "Continue with Google" on Slide 4 before tapping a role card, Google auth completes but nothing happens — they're stuck on Slide 4 with no feedback.
The fix: After Google or Apple auth succeeds and isNewUser: true is detected, if no role has been selected yet, show a bottom sheet modal asking them to pick a role. Once they pick, navigate to the correct signup screen with the Google/Apple profile pre-filled.
Create a RolePickerModal component inline in OnboardingScreen.tsx:

<Modal

  <View style={styles.modalOverlay}>

State and logic:
javascriptconst [showRoleModal, setShowRoleModal] = useState(false);
const [pendingGoogleProfile, setPendingGoogleProfile] = useState(null);

// In onNewUser callback from useGoogleSignIn / useAppleSignIn:
const handleNewSocialUser = (googleProfile) => {
  setPendingGoogleProfile(googleProfile);
  setShowRoleModal(true); // show modal instead of navigating
};

// When user picks role in modal:
const handleModalRoleSelect = (role) => {
  setShowRoleModal(false);
  const params = {
    prefillName: pendingGoogleProfile?.name ?? '',
    prefillEmail: pendingGoogleProfile?.email ?? '',
    prefillAvatar: pendingGoogleProfile?.profileImageUrl ?? '',
    isGoogleSignup: true,
    googleProfile: pendingGoogleProfile
  };
  if (role === 'consumer') navigation.navigate('ConsumerSignup', params);
  if (role === 'business') navigation.navigate('BusinessSignup', params);
  if (role === 'photographer') navigation.navigate('PhotographerSignup', params);
  setPendingGoogleProfile(null);
};
When the modal does NOT show:

If user already tapped a role card THEN tapped Google — role is already known, navigate directly without showing modal. This is the existing flow and must remain unchanged.
