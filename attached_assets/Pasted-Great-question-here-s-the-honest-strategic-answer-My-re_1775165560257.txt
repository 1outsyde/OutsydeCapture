Great question — here's the honest strategic answer:

My recommendation: collect profile photo during signup, defer cover/banner to post-signup
Here's the reasoning broken down by user type:

Profile Photo — collect during signup ✅
Every major platform that has solved this (Instagram, TikTok, LinkedIn, Twitter) asks for a profile photo during signup for one reason — accounts without photos get significantly less engagement and trust. A photographer or business with no profile photo looks abandoned before they've even started.
For Outsyde specifically:

Consumers — optional during signup, prompt them gently. If they signed up via Google, their Google photo is already auto-applied so they're covered
Photographers — should be required or strongly encouraged. A photographer with no profile photo is a credibility problem on a visual platform
Businesses — should be required or strongly encouraged. This becomes their storefront face

Where it fits in the flow:

For Photographers: add it to Step 2 "Your Profile" — it fits perfectly next to Display Name and Bio
For Businesses: add it to Step 2 "Business Info" — it becomes the business logo/avatar
For Consumers: add it as an optional step after password on Step 1, with a clear "Skip for now" option


Cover/Banner — defer to post-signup ✅
The cover banner is higher effort — it needs to be a quality image or video that represents the brand. Asking for it during signup adds friction at the worst moment. Better approach: after they complete signup and land on their profile for the first time, show a prominent prompt:
"Your profile is 60% complete"
[ Add a cover photo to complete your profile → ]
This is a proven pattern — LinkedIn, Spotify, and Airbnb all use post-signup profile completion prompts rather than blocking signup with them.

Photo picker function:
javascriptconst handlePickProfilePhoto = async () => {
  const { status } = await ImagePicker.requestMediaLibraryPermissionsAsync();
  if (status !== 'granted') return;
  
  const result = await ImagePicker.launchImageLibraryAsync({
    mediaTypes: ImagePicker.MediaTypeOptions.Images,
    allowsEditing: true,
    aspect: [1, 1],  // force square crop
    quality: 0.8,
  });
  
  if (!result.canceled) {
    setProfilePhotoUri(result.assets[0].uri);
  }
};
Photo is optional — do not block Continue if no photo selected. Include a small "Optional" label below the circle.
Include profilePhotoUri in the signup payload as profileImageUrl.

CHANGE 2 — Business Step 2 "Business Info": add logo/profile photo upload
Same circular upload component at the top of Step 2, above Business Name. Label it "Business Logo" with "Optional" below. Same picker function and payload inclusion.

CHANGE 3 — Consumer Step 1: add profile photo with clear skip option
For consumers, add the photo upload below the Password field on Step 1. Make it visually lighter — smaller circle, more subdued:
Label: "Profile Photo" with "Optional — you can add this later" below it in muted text.
If the user signed up via Google/Apple and prefillAvatar is already set, show their Google/Apple photo pre-populated in the circle. They can tap to replace it.
